# FastAPI Notes API

REST API quản lý notes sử dụng FastAPI.

## Features

- User registration
- JWT authentication
- Notes CRUD
- Owner authorization
- Pagination
- Search
- Completed status
- Due date
- Tags
- CORS
- Automated tests

## Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- Pydantic
- JWT
- Pytest
